Galcon LightZero / SampledEfficientZero TODOs
============================================

Current agreed v1 assumptions
-----------------------------
- Galcon will live under zoo/board_games/galcon/.
- Tests stay under zoo/board_games/galcon/envs/.
- Initial planet count: num_planets = 8.
- One tick is tick_seconds = 0.25 simulated seconds.
- The game is turn-based for LightZero compatibility.
- Each player action advances the simulation by one tick.
- Discrete action space:
  - action 0 = pass
  - actions 1..N*N = source-target send action
  - source/target are decoded from action - 1
- Send ratio is fixed at 50%.
- min_send_ships = 1 initially.
- Initial K = 16.
- Initial num_simulations = 50.
- Start with seeded random maps.
- Use grid-based observations later.
- Do not finalize model design until grid observation spec is defined.

Clarifications / key concepts
-----------------------------
- max_episode_steps limits one episode/game.
- max_env_step limits the total training run.
- If max_episode_steps = 200 and tick_seconds = 0.25, one game lasts at most 50 simulated seconds.
- In play_with_bot_mode, one outer env.step may apply two internal ticks:
  - agent tick
  - bot tick
  This may affect how we set game_segment_length later.
